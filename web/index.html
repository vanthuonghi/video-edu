Chưa có scene nào. Viết một câu ở trên, bấm “+ Scene”, hoặc nhập chủ đề ở cột phải để AI viết kịch bản (cần LLM_API_KEY trên repo).

Kết nối GitHub

Token chỉ lưu trong localStorage của trình duyệt này và chỉ gửi tới api.github.com. Tạo token tại GitHub → Settings → Developer settings.
